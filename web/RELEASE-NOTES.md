# SUNBOUND Alpha 0.8

HTML5 pixel-art ARPG: 6 classes, 96 Active + 48 Support Gems, 48 passive nodes, 12 specialisations, 5 islands / 25 procedural maps, equipment/refining/cards, island quests and Co-op.

- **SUNBOUND-PLAY-OFFLINE.zip**: extract and open SUNBOUND/index.html in Chrome or Edge. Single player; no Node.js required.
- **SUNBOUND-online-server.zip**: Node.js 22.13+ (24 LTS recommended); extract, run npm ci and npm start. Account-backed saves use .local/accounts.sqlite. Keep this database directory when upgrading.
- The static website supports single player. Co-op and account saves require the separate server.
- SPRITE-CHECK.png: review of all 96 character poses.
